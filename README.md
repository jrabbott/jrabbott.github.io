# Jon Abbott

Personal site: home, blog, spec, projects, and online links.

**Live:** https://jrabbott.github.io

## Stack

- [Astro](https://astro.build) (static)
- Markdown / MDX content collections
- GitHub Pages via Actions

## Develop

```bash
npm install
npm run dev
```

## Build

```bash
npm run build
npm run preview
```

Requires Node 22+.
